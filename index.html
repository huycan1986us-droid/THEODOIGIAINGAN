Đồng bộ số liệu nhiều máy tính cùng lúc (qua Google Sheets — Miễn phí)

Khi kết nối với Google Sheets, mọi thay đổi trên 1 máy sẽ tự động cập nhật sang tất cả máy tính khác mỗi 20 giây mà không cần tải đè file lên GitHub.

Chưa kết nối

Chưa cấu hình đường dẫn đồng bộ. Làm theo 4 bước bên dưới để kích hoạt.

4 bước tạo kho dữ liệu chung bằng Google Sheets (chỉ làm 1 lần)

  1. Tạo 1 file Google Trang tính (Google Sheets) mới trên Google Drive của bạn (ví dụ đặt tên: Du lieu Giai ngan 2026).
  2. Trên thanh menu chọn Tiện ích mở rộng (Extensions) → Apps Script, xóa hết code mẫu, dán đoạn mã bên dưới vào và bấm Lưu (Ctrl + S).
  3. Bấm Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment) → chọn loại Ứng dụng web (Web app) → mục Thực thi dưới tư cách chọn Tôi (Me), mục Người có quyền truy cập chọn Bất kỳ ai (Anyone) → bấm Triển khai và cấp quyền → sao chép URL ứng dụng web.
  4. Dán URL vừa sao chép vào dòng const DEFAULT_SYNC_URL = '...'; ở đầu phần <script> trong file index.html trên GitHub (làm 1 lần duy nhất) rồi bấm Đẩy 29 dự án hiện tại lên Google Sheets. Từ đó mọi máy mở web sẽ tự đồng bộ cùng lúc!
function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('Data') || ss.insertSheet('Data');
  var raw = sheet.getRange('A1').getValue();
  var updatedAt = sheet.getRange('B1').getValue() || '';
  var payload = raw ? JSON.parse(raw) : null;
  return ContentService.createTextOutput(JSON.stringify({
    status: 'ok',
    updatedAt: updatedAt,
    projects: payload
  })).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var body = JSON.parse(e.postData.contents);
    var projects = body.projects;
    if (!Array.isArray(projects)) throw new Error('Invalid projects');
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName('Data') || ss.insertSheet('Data');
    var now = new Date().toISOString();
    sheet.getRange('A1').setValue(JSON.stringify(projects));
    sheet.getRange('B1').setValue(now);

    // Tự động ghi thêm bảng dễ đọc vào sheet BaoCao
    var report = ss.getSheetByName('BaoCao') || ss.insertSheet('BaoCao');
    report.clearContents();
    var rows = [['STT', 'Tên dự án', 'Quyết định', 'Tổng KHV 2026', 'Đã giải ngân', 'Còn lại', 'Tỷ lệ (%)']];
    for (var i = 0; i < projects.length; i++) {
      var p = projects[i];
      var khv = 0, gn = 0;
      for (var k in p.sources) {
        khv += Number(p.sources[k].khv) || 0;
        gn += Number(p.sources[k].gn) || 0;
      }
      var rate = khv > 0 ? (gn / khv * 100).toFixed(2) : '0.00';
      rows.push([p.id, p.name, p.quyetDinh || '', khv, gn, Math.max(0, khv - gn), rate + '%']);
    }
    report.getRange(1, 1, rows.length, 7).setValues(rows);

    return ContentService.createTextOutput(JSON.stringify({
      status: 'ok',
      updatedAt: now
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      status: 'error',
      message: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}

Hướng dẫn đưa Web App lên GitHub & phát hành miễn phí qua GitHub Pages

Vì toàn bộ ứng dụng nằm gọn trong 1 file HTML duy nhất, bạn chỉ cần đổi tên file thành index.html và tải lên GitHub.

Cách 1 — Khuyên dùng

Tải trực tiếp trên trình duyệt (không cần cài Git)

  1. Tải file web app này về máy và đổi tên thành index.html.
  2. Đăng nhập github.com → bấm dấu + (góc trên bên phải) → chọn New repository.
  3. Đặt tên repo (ví dụ: theo-doi-giai-ngan-2026), chọn Public → bấm Create repository.
  4. Trong trang repo mới tạo, bấm vào liên kết uploading an existing file → kéo thả file index.html vào → bấm Commit changes.
  5. Vào tab Settings → chọn mục Pages ở thanh bên trái → tại phần Branch chọn main và thư mục / (root) → bấm Save.
  6. Chờ khoảng 1–2 phút, tải lại trang sẽ thấy đường dẫn web công khai dạng: https://<ten-tai-khoan>.github.io/theo-doi-giai-ngan-2026/.
Cách 2

Đẩy code bằng dòng lệnh Git (Terminal / Command Prompt)

mkdir theo-doi-giai-ngan-2026
cd theo-doi-giai-ngan-2026
# Chép file web app vào thư mục này và đổi tên thành index.html

git init
git add index.html
git commit -m "Khởi tạo web app theo dõi giải ngân vốn đầu tư công 2026"
git branch -M main
git remote add origin https://github.com/<TEN_TAI_KHOAN>/theo-doi-giai-ngan-2026.git
git push -u origin main

Lưu ý: Sau khi đẩy lên GitHub, dữ liệu chỉnh sửa trực tiếp trên web được lưu tại trình duyệt của từng người dùng (localStorage). Để chia sẻ số liệu mới nhất cho cả đơn vị, hãy bấm nút Sao lưu dữ liệu (JSON) hoặc cập nhật file index.html trên GitHub.
