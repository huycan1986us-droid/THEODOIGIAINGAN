Hướng dẫn đưa Web App lên GitHub & phát hành miễn phí qua GitHub Pages

Vì toàn bộ ứng dụng nằm gọn trong 1 file HTML duy nhất, bạn chỉ cần đổi tên file thành index.html và tải lên GitHub.

Cách 1 — Khuyên dùng

Tải trực tiếp trên trình duyệt (không cần cài Git)

  1. Tải file web app này về máy và đổi tên thành index.html.
  2. Đăng nhập github.com → bấm dấu + (góc trên bên phải) → chọn New repository.
  3. Đặt tên repo (ví dụ: theo-doi-giai-ngan-2026), chọn Public → bấm Create repository.
  4. Trong trang repo mới tạo, bấm vào liên kết uploading an existing file → kéo thả file index.html vào → bấm Commit changes.
  5. Vào tab Settings → chọn mục Pages ở thanh bên trái → tại phần Branch chọn main và thư mục / (root) → bấm Save.
  6. Chờ khoảng 1–2 phút, tải lại trang sẽ thấy đường dẫn web công khai dạng: https://<ten-tai-khoan>.github.io/theo-doi-giai-ngan-2026/.
Cách 2

Đẩy code bằng dòng lệnh Git (Terminal / Command Prompt)

mkdir theo-doi-giai-ngan-2026
cd theo-doi-giai-ngan-2026
# Chép file web app vào thư mục này và đổi tên thành index.html

git init
git add index.html
git commit -m "Khởi tạo web app theo dõi giải ngân vốn đầu tư công 2026"
git branch -M main
git remote add origin https://github.com/<TEN_TAI_KHOAN>/theo-doi-giai-ngan-2026.git
git push -u origin main

Lưu ý: Sau khi đẩy lên GitHub, dữ liệu chỉnh sửa trực tiếp trên web được lưu tại trình duyệt của từng người dùng (localStorage). Để chia sẻ số liệu mới nhất cho cả đơn vị, hãy bấm nút Sao lưu dữ liệu (JSON) hoặc cập nhật file index.html trên GitHub.
